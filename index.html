tomim-skills

Agent skills I use daily across Cursor and Claude Code.

Install View on GitHub

Problems it solves

Skill drift across tools

Cursor and Claude Code each want their own skills folder, so you end up copy-pasting and they fall out of sync. tomim-skills makes ~/.cursor/skills and ~/.claude/skills symlinks to a single skills/ directory, so both agents read from the same source.

Mixing your own workflows with third-party skill packs

Vendor packs like Impeccable live in their own repos and update on their own cadence. They're tracked here as git submodules under vendor/ and exposed through symlinks in skills/, so one command updates everything: ./install.sh --update-vendor.

No central place to collect, curate, and author skills

Good skills come from everywhere: ones you refined in chat, vendor packs you found on GitHub, forks of someone else's idea, half-finished drafts. Without a hub they scatter into dotfiles, gists, and Slack messages, and you lose track of which ones you actually use. This repo is the hub. Drop your own skills in as folders under skills/, pull in vendor packs as submodules under vendor/, prune what you've outgrown, and replicate the whole set to a new machine with one install script. Authoring, updating, curating, and syncing all run through the same place, version-controlled, on your own cadence.

How it works

Both Cursor and Claude Code discover skills from a single directory. Own skills live as regular folders under skills/. Vendor skills are symlinks pointing into git submodules under vendor/.

Skills

GitHub workflow

pr-dashboard own

One-shot status overview of all your open PRs in a repo: title, review state, CI checks, open comments, and a recommended next step per PR. Use when you want to know which PR to babysit next.

miguel-review own

Opinionated diff review against a base branch. Biased toward minimal diffs, deletions over additions, zero tolerance for dead code or premature abstractions. Reports only high-signal issues.

gh-pr-comment-assistant own

Pulls the latest review comments on the current branch's PR, groups them by reviewer and file, summarizes what each one is asking for, and helps plan fixes.

gh-issue-creator own

Creates a GitHub issue using one of the repo's templates (bug, feature, tech debt) or a blank issue. Pulls labels dynamically and keeps the description concise.

gh-pr-description-updater own

Reads or rewrites the current PR's description, strictly following the repo's PR template. Enforces brevity and template compliance.

verify-pr own

Three-phase PR verification: code review (delegates to miguel-review), test plan with gap analysis and execution, and validation of upstream assumptions. Produces a structured report.

ui-review own

Comprehensive frontend UI review across typography, layout, accessibility, responsiveness, copy, and visual polish. Inspects the page in a browser and produces a prioritized list of small, concrete fixes (never rewrites).

update-branch own

Pulls the latest from main and merges it into the current working branch. Use when you want to sync a feature branch without leaving the agent.

Writing

writing-voice own

Writes or rewrites content in a direct, personal, sensory voice. Bans AI-giveaway phrases, enforces visual formatting, and includes platform-specific guidance for LinkedIn, X, blog, email, and technical writing.

Authoring skills

create-skill own

Guide for authoring or auditing agent skills: gathers requirements, writes SKILL.md with frontmatter, structures supporting files, and verifies quality. Forked from Cursor's built-in version.

Design

impeccable vendor

Single skill with 20 internal commands for designing, critiquing, polishing, and animating frontend interfaces. Commands include craft, shape, audit, critique, animate, bolder, colorize, delight, layout, and polish. v3.0.7, from pbakaus/impeccable.

review-animations vendor

Reviews animation and motion code against a high craft bar derived from Emil Kowalski's design-engineering philosophy: justified motion, frequency-appropriate timing, responsive easing, sub-300ms UI, correct transform-origin, interruptibility, GPU-only properties, and reduced-motion. Emits a Before/After/Why findings table and a Block/Approve verdict. From emilkowalski/skill.

Setup

Install all skills

curl -fsSL https://raw.githubusercontent.com/tomimor/tomim-skills/main/install.sh | bash -s -- --all

Install a single skill

curl -fsSL https://raw.githubusercontent.com/tomimor/tomim-skills/main/install.sh | bash -s -- --skill pr-dashboard

Update vendor skills

./install.sh --update-vendor

Install flags

FlagDescription
--allInstall all skills (non-interactive)
--skill <name>Install a single skill by name
--target <dir>Override the install directory
--forceOverwrite existing skills without confirming
--update-vendorUpdate vendor submodules to their latest versions
